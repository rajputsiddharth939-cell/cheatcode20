# CHEATCODE™ Launch Website

Production-style React + Vite + Tailwind CSS launch site.

## Stack
- React 19
- Vite
- Tailwind CSS v4
- Lucide React
- Custom responsive CSS for the editorial/FMCG layout

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy
Push the folder to GitHub and import the repository into Vercel or Netlify.

The Google Apps Script signup endpoint is already wired into `src/App.jsx`.

Launch countdown is set to **11 October 2026, India time (UTC+05:30)**.
